# 浏览器插件

[extension/](../extension/) 是一个 Chrome 插件（manifest v3，不用打包，直接加载目录），做三件事：

1. 把 Chrome 里闲鱼的登录同步给管理后台，让账号能自动续期；
2. 在拼多多商品页上一键导入商品，作为[拼多多货源](features.md#拼多多货源)；
3. 给[暂存](features.md#搜索和暂存)的闲鱼商品拿完整描述和全部图片。

## 安装

1. Chrome 打开 `chrome://extensions`，右上角打开"开发者模式"，点"加载已解压的扩展程序"，选这个项目的 `extension` 目录；
2. 在管理后台左下角的用户菜单里点「浏览器插件令牌」生成一个，复制到插件弹窗的「插件令牌」里；
3. 插件弹窗里填管理后台的地址，默认 http://127.0.0.1:8000。本机的地址可以是 http，别的只能是 https；
   填了远程地址时 Chrome 会问一次要不要允许插件访问这个地址，点允许（只给这一个地址的权限）。

插件更新以后，在 `chrome://extensions` 里点一下这个插件的刷新按钮，新加的权限才生效；已经开着的管理后台页面也要刷新一下才连得上插件。

## 同步闲鱼登录

扫码登录的会话平台不给开"保持登录"，过期后只能重新扫。浏览器里登录的能开，所以用插件把浏览器的登录同步过来：

1. 在 Chrome 里登录 goofish.com，头像菜单里打开"保存登录信息"；
2. 插件把登录推给管理后台，推过来的账号归到插件令牌的主人名下；
3. 之后浏览器里登录变了（重新登录、网页端自动续期）都会自动同步，另外每 10 分钟对一次。点插件图标能看同步结果。

后台收到登录先向平台确认能用再保存；和已保存的一样就不请求平台；浏览器那份已经过期就拒绝，不替它续期，留着后台自己那份。
后台和浏览器共用这次登录，浏览器里退出登录，这里也会失效。

没装插件时，登录弹窗的「导入浏览器登录」可以手动粘贴开发者工具里 www.goofish.com 那条请求的 Cookie 请求头，效果一样。

## 导入拼多多商品

1. 在装了插件的 Chrome 里登录拼多多（mobile.yangkeduo.com，App 里分享的链接打开也是这个）；
2. 打开商品页，点插件图标里的「导入这个商品」；
3. 弹窗里会说导入了几张图、几个规格，点「到管理后台查看」打开那个货源。

插件只在点按钮的时候读当前这个标签页（Chrome 的 activeTab，不常驻在拼多多页面上），读的是页面里已经有的商品数据，不另外请求拼多多。

## 拿暂存商品的详情

插件 0.4.0 起。插件往填的那个管理后台的页面里注入一段传话脚本（`bridge.js`）。在搜索页点「暂存」或者在暂存详情里点「拉详情」时：

1. 插件在这个 Chrome 里后台开一个标签页，打开那件商品的闲鱼页面；
2. 用页面自己的请求库拿详情（`goofish.js`），拿完关掉；一次一件，两件之间停一下；
3. 闲鱼要验证时那个标签页会留着并切到前面，过一下滑块再拉。

用的是这个 Chrome 里的闲鱼登录（没登录也能看）。后台服务端不调商品详情接口，原因见[协议笔记](protocol-notes.md#看别人的商品详情)。

## 权限和安全

- 插件只读 goofish.com 的 cookie，只发给填的那个管理后台；
- 插件令牌只能用来推登录和导入拼多多商品，别的接口都不认；
- 令牌忘了或者泄露了，在用户菜单里重新生成，旧的马上作废。

## 文件

```
manifest.json    manifest v3
background.js    cookie 变化和每 10 分钟时推给 /api/login/import（带插件令牌），登录没变不推；
                 弹窗读出来的拼多多商品推给 /api/pdd/goods；管理后台页面要的商品详情排队在后台标签页里拿
bridge.js        注入到管理后台页面里的传话脚本：页面 postMessage 要详情，转给 background.js，结果交回页面
goofish.js       注入到闲鱼商品页里跑的函数：用页面自己的 lib.mtop 调商品详情，挑出描述、图片、价格、计数
pdd.js           注入到拼多多商品页里跑的函数：从 window.rawData 里挑出商品数据
lib.js           纯函数（拼 cookie、登录指纹、只允许本机地址、认拼多多商品页、传话脚本注入到哪），可以直接用 node 测
popup.html/js    弹窗：导入拼多多商品，同步结果、立即同步、管理后台地址、插件令牌
icons/           插件图标（奶蛙回眸）；16px 的只取头部，小了也看得出眼睛
```
